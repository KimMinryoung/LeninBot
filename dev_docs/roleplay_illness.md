# 역할극 질병 상태

구현: `runtime_tools/roleplay_illness.py`. 현재 지원 질병은 `pneumonia`(폐렴)이다.
부상 목록 `injuries`와 별도로 `character_state.illnesses` JSON 목록에 저장한다.
기존 저장에는 읽을 때 빈 목록을 제공하며 사료·몸 상태 문자열에서 발병을 소급 생성하지 않는다.
빈 목록은 등록된 질병이 없다는 뜻이며 건강하다는 확정이 아니다.

## 기록과 판정

각 기록은 kind, status(active/worsening/recovering/resolved), severity(unknown/mild/moderate/severe),
treatment(unknown/untreated/treated), fever(unknown/yes/no), elapsed_minutes, source, scope_id를 가진다.
elapsed_minutes는 발병 시점부터의 실제 병력이 아니라 엔진이 **등록 이후 계산한 활동 구간**의 분이다.
활동 미상의 다음 날 생략 구간은 질병 경과에 더하지 않는다.

Jev의 기존 `roleplay-records` 호출에 폐렴 경과·중증도·치료·발열의 네 선택형 질문을 추가한다.
현재 장면의 명시적 발병·진단 또는 경과 변화만 판정하며, 과거 사료·가정·계획은 keep이다.
열·기침·상처만으로 폐렴을 진단하지 않는다. 상처 처치는 폐렴 치료가 아니며, 치료 시작은 회복 완료가 아니다.
질병 라벨에는 핵심 accept 기준(현재 설정 0.65)을 적용한다. 미응답·저신뢰·기록 판정 장애는 기존 값을 유지한다.
질병 판정 때문에 별도 생성 모델 호출을 추가하지 않는다. 기존 records 그룹이 비어 있던 장면에는 이 그룹 호출이 생긴다.

새 발병·치료·경과 변경은 초안의 끝 시점에 적용한다. 직전 구간은 기존 질병 상태로 계산하며
예정 사건으로 초안 끝에 도달하지 못하면 끝 시점 질병 변화를 적용하지 않는다.
초안·질병·메모는 기존 revision 검사와 단일 SQLite 확정 트랜잭션을 사용한다.
같은 scope 재처리는 중복 적용하지 않는다. 에이전트의 직접 illnesses 쓰기는 허용하지 않는다.
reset은 질병 기록을 비우며, resolved 기록은 남겨서 회복 완료를 보여 준다.
회복 후 명시적 재발이면 계산 분과 이전 치료·발열·중증도를 초기화한다.

## 시간 효과

다음은 역할극의 게임 상수이며 실제 폐렴의 예후·치료 효과를 예측하는 값이 아니다.

| 현재 상태 | 시간당 효과 |
|---|---|
| mild / moderate / severe | 피로 변화에 각각 +0.5 / +1 / +2 추가 |
| severity=unknown | 중증도에 따른 피로 가산 없음 |
| fever=yes | 깨어 있는 구간의 명료함 변화에 −1 추가 |
| recovering | 위 가산·감산을 절반으로 적용 |
| resolved | 질병 효과 및 계산 분 누적 중단 |

기존 휴식·수면 효과에 더하므로 피로 회복 속도를 낮출 수 있다. 명료함은 기존 하한을 유지한다.
치료 여부만으로 수치를 즉시 회복시키지 않는다. 시간만으로 악화·완치·사망을 추정하지 않는다.
1분 적분으로 기존 정산에 연결되며 한 시간을 나눠 계산해도 같은 결과를 낸다.
`last_calculation.conditions.illnesses`와 상태 이력에서 적용 근거를 확인할 수 있다.

## 표시·연기·검토

`/status`는 질병명·경과·중증도·치료·발열을 표시하고 확정 한 줄은 질병 갱신을 알린다.
연기 모델과 검토 모델은 `actor_state_view.illnesses`의 질적 상태만 받는다.
경과 분·게임 계수·내부 근거/메시지 ID는 연기 문맥에서 제외한다.
새 현재 질병은 사용자 지시와 초안에서 확정되어야 하며 과거 폐렴 사료만으로 기존 운영 상태를 변경하지 않는다.

검증: `venv/bin/python -m unittest discover -s tests -p 'test_roleplay*.py'`.
`test_roleplay_illness.py`는 상태 호환성, 발병/치료/회복/재발, 효과 적분, 판정 장애 보존,
서술 전용 뷰, 잘못된 기록 거절, 저장·재처리·직접 쓰기 제한을 검사한다.
실제 Jev의 질병 판독 정확도는 모의 응답 테스트와 별도로 확인해야 한다.

질병 경과와 증상·치료는 독립 판정한다. 이미 등록된 폐렴은 매 장면 병명을 반복하지 않아도
현재 환자의 명시적 발열과 처방약 실제 복용을 반영한다. 발열은 관찰 상태이며 폐렴만이 유일한
원인이라는 증명을 요구하지 않는다. 치료받음은 약물 효과나 완치를 뜻하지 않는다. 새 근거가 없으면
unknown으로 덮어쓰지 않고 keep을 선택하도록 한다. /status는 항상 상세 상태를 구역별로 표시한다.
